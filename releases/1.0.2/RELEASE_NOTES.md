## 本版变化

- Visual Studio 工具窗口将提交说明、变更预览和模型设置分开。可在「提交说明」页刷新或切换范围，在「查看变更」页核对文件和差异。
- VS Code 生成完成后在状态栏提示审核，模型请求次数和 Token 用量写入输出日志。出错时可从提示直接打开日志。
- 差异预览被截断时会显示提示。模型生成失败且已提取部分事实时，替换草稿的提示会明确标为「部分摘要」。

## 安装与验证

按编辑器选择 VS2019、VS2022（17.14）或 VSCode 安装包。三个安装包的 SHA-256 校验值见附件 `SHA256SUMS.txt`。

33 项 .NET 测试和 21 项 Node 测试全部通过。模型请求使用模拟测试，编辑器 GUI 验收与真实 TFVC 服务器联调尚未执行。
