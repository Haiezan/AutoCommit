## 本版变化

- Visual Studio 读取 TFVC 变更时使用记录的文本编码。GBK 和 UTF-8 文件可以在同一组变更中生成中文差异，文件转换编码时分别解码基线和本地版本。
- Visual Studio 和 VS Code 读取 Git 暂存差异时优先尝试 UTF-8，解码失败后尝试 GBK。预览和分批生成使用同一份解码结果。
- Visual Studio 在 Git 暂存区为空时显示可用操作。有变更时可确认「暂存全部并生成说明」，工作区干净时给出提示。已有部分暂存时，生成范围仍为暂存区。

## 安装与验证

按编辑器选择 VS2019、VS2022（17.14）或 VSCode 安装包。三个安装包的 SHA-256 校验值见附件 `SHA256SUMS.txt`。

37 项 .NET 测试和 22 项 Node 测试全部通过。混合编码测试检查了模拟模型收到的差异内容。本次发布尚未进行编辑器界面验收、真实模型服务或 TFVC 服务器联调。
